## Context

What situation forces a decision? The constraints, the forces in tension, the
things that were true when this was written. State the problem, not the answer.

## Decision

What we chose. Be specific and concrete — name the mechanism, the interface, the
rule. Write it as "we will ..." so it reads as a commitment.

## Consequences

honestly — an ADR with no negative consequences is usually hiding one. Note any
follow-on decisions this enables or forecloses.
